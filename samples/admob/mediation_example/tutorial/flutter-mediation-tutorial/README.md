# Flutter 广告中介（Mediation）完整教程

本教程面向中级到高级 Flutter 开发者，帮助你深入学习如何在 Flutter 应用中集成 Google Mobile Ads 的广告中介（Mediation）功能。如果你已经熟悉 Google Mobile Ads 的基础使用，想要了解如何通过中介从多个广告网络获取广告，这个教程非常适合你。

## 学习目标

完成本教程后，你将能够：

- 理解广告中介的概念、工作原理和优势
- 正确配置项目以支持广告中介
- 掌握 SDK 初始化和适配器状态检查
- 在 AdMob 控制台中配置中介组和广告网络
- 为 Android 和 iOS 平台添加中介适配器库
- 使用 Platform Channel 调用第三方 SDK API
- 配置网络特定参数（Network Extras）
- 检测和识别广告来源网络
- 遵循最佳实践，优化广告收益
