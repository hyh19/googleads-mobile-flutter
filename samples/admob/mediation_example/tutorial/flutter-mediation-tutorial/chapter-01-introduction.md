# 第 1 章 广告中介简介

## 引言

广告中介（Mediation）是 Google Mobile Ads 提供的一项强大功能，允许你从多个广告网络获取广告，而不仅仅依赖 AdMob。通过中介，你可以最大化广告填充率和收益。本章将介绍广告中介的基本概念、工作原理和优势。

## 什么是广告中介？

广告中介（Mediation）是一种技术，允许你的应用从多个广告网络（Ad Networks）获取广告。当你的应用请求广告时，中介会自动选择最适合的广告网络来提供广告，通常基于 eCPM（有效每千次展示成本）或其他优化策略。

### 核心概念

- **广告网络（Ad Network）**：提供广告的第三方服务，如 AppLovin、Unity Ads、IronSource 等
- **适配器（Adapter）**：连接 Google Mobile Ads SDK 和第三方广告网络的桥梁
- **中介组（Mediation Group）**：在 AdMob 控制台中配置的一组广告网络，按优先级排序
- **eCPM**：有效每千次展示成本，用于决定广告网络的优先级

## 为什么使用广告中介？

### 1. 提高广告填充率

单一广告网络可能无法在所有情况下都提供广告。通过中介，你可以从多个网络获取广告，大大提高广告填充率。

### 2. 最大化收益

中介会自动选择 eCPM 最高的广告网络，帮助你最大化广告收益。

### 3. 简化集成

不需要为每个广告网络单独集成 SDK。你只需要集成 Google Mobile Ads SDK，然后添加相应的适配器库。

### 4. 统一管理

在 AdMob 控制台中统一管理所有广告网络，包括优先级、eCPM 设置等。

## 广告中介的工作原理

### 工作流程

1. **应用请求广告**：你的应用通过 Google Mobile Ads SDK 请求广告
2. **中介选择网络**：中介根据配置的优先级和 eCPM，依次尝试各个广告网络
3. **网络返回广告**：第一个有可用广告的网络返回广告
4. **应用显示广告**：应用显示返回的广告

### 优先级机制

中介按照以下顺序尝试广告网络：

1. **AdMob**：首先尝试 AdMob 自己的广告
2. **配置的网络**：按照在 AdMob 控制台中配置的优先级依次尝试
3. **Waterfall 模式**：如果高优先级网络没有广告，自动尝试下一个网络

### 实时竞价（Real-Time Bidding）

现代中介还支持实时竞价（RTB），多个网络同时竞价，选择出价最高的网络。

## 支持的第三方广告网络

Google Mobile Ads 支持众多第三方广告网络，包括但不限于：

- **AppLovin**：移动应用广告平台
- **Unity Ads**：游戏广告网络
- **IronSource**：移动广告平台
- **Vungle**：视频广告网络
- **Chartboost**：游戏广告平台
- **AdColony**：视频广告网络
- **Facebook Audience Network**：Facebook 广告网络
- **Tapjoy**：移动广告和货币化平台

每个网络都有对应的适配器库，需要在项目中添加相应的依赖。

## 与直接集成广告网络的对比

### 直接集成方式

- **优点**：
  - 完全控制广告请求流程
  - 可以自定义选择逻辑
- **缺点**：
  - 需要为每个网络单独集成 SDK
  - 代码复杂度高
  - 难以统一管理和优化

### 中介方式

- **优点**：
  - 统一集成，代码简单
  - 自动优化，最大化收益
  - 统一管理，易于配置
- **缺点**：
  - 对底层控制较少
  - 需要理解适配器概念

## 实现流程概览

集成广告中介的主要步骤：

1. **项目配置**：添加依赖和配置平台设置
2. **SDK 初始化**：初始化 Mobile Ads SDK，检查适配器状态
3. **AdMob 控制台配置**：在控制台中配置中介组和广告网络
4. **添加适配器库**：在 Android 和 iOS 项目中添加适配器依赖
5. **配置网络参数**：为特定网络配置参数（如 AppLovin SDK Key）
6. **调用第三方 API**：使用 Platform Channel 调用第三方 SDK API（如需要）
7. **配置 Network Extras**：为特定网络传递额外参数
8. **检测广告来源**：识别广告来自哪个网络，用于分析和优化

## 适配器（Adapter）的作用

适配器是连接 Google Mobile Ads SDK 和第三方广告网络的桥梁。每个广告网络都有对应的适配器：

- **功能**：将 Google Mobile Ads SDK 的广告请求转换为第三方网络的请求格式
- **位置**：作为依赖库添加到项目中
- **初始化**：在 SDK 初始化时自动初始化

### 适配器状态

每个适配器都有初始化状态：

- **READY**：适配器已准备好，可以请求广告
- **NOT_READY**：适配器未准备好，可能正在初始化
- **MISSING**：适配器库未添加或未找到
