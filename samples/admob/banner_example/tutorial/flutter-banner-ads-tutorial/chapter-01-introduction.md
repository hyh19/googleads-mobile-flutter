# 第 1 章：Banner Ads 简介

## 章节简介

在本章中，我们将介绍 Banner Ads（横幅广告）的基本概念、使用场景和优势，帮助你理解为什么以及何时应该使用这种广告格式。我们还将介绍自适应横幅广告的概念，为后续章节的学习打下基础。

## 什么是 Banner Ads

Banner Ads（横幅广告）是移动应用中最常见的广告格式之一，通常以矩形横幅的形式显示在应用界面的顶部或底部。与全屏广告不同，Banner Ads 不会完全覆盖应用内容，用户可以在查看广告的同时继续使用应用。

### 核心特征

Banner Ads 具有以下核心特征：

- **非侵入性**：不会完全覆盖应用内容，用户可以继续使用应用
- **持续显示**：可以长时间显示在界面上，提供持续的曝光
- **多种尺寸**：支持多种标准尺寸和自适应尺寸
- **易于集成**：实现相对简单，适合大多数应用场景

## 使用场景和优势

### 典型使用场景

Banner Ads 最适合以下场景：

1. **应用主界面**：在应用的主界面底部或顶部显示
2. **列表页面**：在列表内容之间或底部显示
3. **详情页面**：在内容详情页面的底部显示
4. **游戏界面**：在游戏菜单或暂停界面显示

### 主要优势

使用 Banner Ads 可以带来以下优势：

- **用户体验友好**：不会打断用户操作，用户可以继续使用应用
- **持续曝光**：广告长时间显示，提供持续的曝光机会
- **实现简单**：集成相对简单，代码量较少
- **性能影响小**：对应用性能的影响相对较小
- **收入稳定**：可以提供稳定的广告收入来源

## 与其他广告格式的区别

为了更好地理解 Banner Ads，让我们将其与其他常见的广告格式进行对比：

### Banner Ads vs 插屏广告（Interstitial Ads）

| 特性 | Banner Ads | 插屏广告 |
|------|-----------|---------|
| 显示方式 | 部分屏幕，不覆盖内容 | 全屏显示 |
| 用户交互 | 可以忽略继续使用 | 必须关闭才能继续 |
| 显示时长 | 持续显示 | 临时显示 |
| 视觉冲击 | 中等 | 高 |
| 收入潜力 | 中等 | 高 |

### Banner Ads vs 原生广告（Native Ads）

| 特性 | Banner Ads | 原生广告 |
|------|-----------|---------|
| 外观 | 标准横幅样式 | 可自定义样式 |
| 集成复杂度 | 简单 | 复杂 |
| 用户体验 | 明显是广告 | 融入内容 |
| 灵活性 | 较低 | 高 |

## 自适应横幅广告

### 什么是自适应横幅广告

自适应横幅广告（Anchored Adaptive Banner）是 Google Mobile Ads SDK 推荐使用的 Banner Ads 格式。它会根据设备的屏幕宽度自动调整广告尺寸，确保在不同设备上都能获得最佳的显示效果。

### 自适应横幅的优势

- **自动适配**：根据屏幕宽度自动调整尺寸
- **最佳效果**：在不同设备上都能获得最佳显示效果
- **简化开发**：无需手动计算不同设备的广告尺寸
- **提高填充率**：自适应尺寸通常有更高的广告填充率

### 固定尺寸 vs 自适应尺寸

**固定尺寸**：

```dart
// 使用固定的广告尺寸
BannerAd(
  adUnitId: adUnitId,
  size: AdSize.banner, // 固定尺寸 320x50
  // ...
)
```

**自适应尺寸**：

```dart
// 使用自适应广告尺寸
final size = await AdSize.getCurrentOrientationAnchoredAdaptiveBannerAdSize(
  MediaQuery.of(context).size.width.truncate(),
);
BannerAd(
  adUnitId: adUnitId,
  size: size, // 自适应尺寸
  // ...
)
```

## 实现流程概览

实现 Banner Ads 的完整流程包括以下主要步骤：

### 1. 项目配置

- 添加 `google_mobile_ads` 依赖
- 配置 Android 和 iOS 平台
- 获取广告单元 ID

### 2. 确定广告尺寸

- 使用 `AdSize.getCurrentOrientationAnchoredAdaptiveBannerAdSize()` 获取自适应尺寸
- 或使用固定的标准尺寸

### 3. 加载广告

- 创建 `BannerAd` 对象
- 设置广告单元 ID 和尺寸
- 实现 `BannerAdListener` 处理加载结果
- 调用 `load()` 方法加载广告

### 4. 显示广告

- 使用 `AdWidget` 包装广告对象
- 在 `Stack` 中定位广告
- 使用 `SafeArea` 确保安全显示

### 5. 处理方向变化

- 使用 `OrientationBuilder` 检测方向变化
- 在方向变化时重新加载广告

### 6. 监听广告事件

- 实现 `BannerAdListener` 的各种回调
- 处理广告加载、点击、展示等事件

### 7. 集成同意管理

- 实现用户同意管理（UMP）
- 在获得同意后加载广告

## 核心概念

在深入学习实现细节之前，让我们先了解几个核心概念：

### 广告单元 ID（Ad Unit ID）

广告单元 ID 是 Google AdMob 为你的应用分配的唯一标识符，用于标识特定的广告位置。每个平台（Android 和 iOS）都有独立的广告单元 ID。

### 广告尺寸（Ad Size）

广告尺寸定义了横幅广告的宽度和高度。可以使用固定尺寸（如 320x50）或自适应尺寸（根据屏幕宽度自动调整）。

### 广告加载（Ad Loading）

广告加载是指从 Google 广告服务器请求广告内容的过程。Banner Ads 的加载通常需要几秒钟的时间。

### 广告显示（Ad Displaying）

广告显示是指将已加载的广告呈现给用户的过程。只有在广告成功加载后，才能进行显示。

### 广告事件（Ad Events）

广告事件是在广告生命周期的不同阶段触发的回调，用于处理广告加载、点击、展示等事件。
