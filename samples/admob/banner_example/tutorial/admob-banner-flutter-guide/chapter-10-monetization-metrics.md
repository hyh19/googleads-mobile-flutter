# 第 10 章 变现指标与优化建议

本章提供 Banner 变现常见指标和优化思路，帮助你在上线后持续提升收益。

## 简介

关键指标包括填充率、展示次数、点击率、eCPM。通过合理的请求时机、版位位置与实验可以提升整体收益。

## 核心步骤

1. 观察填充率与 eCPM：填充低时检查地区、流量质量与政策。
2. 控制请求频率：仅在页面可见时加载 Banner，避免无效请求。
3. 版位位置：通常底部 SafeArea 更稳妥，避免遮挡主内容。
4. 进行 A/B 实验：调整关键词、位置或请求时机对比效果。

## 代码示例

利用回调记录指标事件：

```dart
onAdImpression: (Ad ad) {
  debugPrint("Ad recorded an impression.");
},
onAdClicked: (Ad ad) {
  debugPrint("Ad was clicked.");
},
```

## 练习与检查

- 设计一次简单的 A/B：对比页面加载即请求 vs 首次可见时请求。
- 统计一段时间的填充率与 eCPM，识别地区差异。
- 检查日志中是否存在频繁失败的错误码，避免浪费请求。

## 小结

通过监测指标与小步实验，你可以持续优化 Banner 版位的收益表现。
