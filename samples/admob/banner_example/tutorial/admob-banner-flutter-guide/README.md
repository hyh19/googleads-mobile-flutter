# Flutter AdMob Banner 集成与优化教程

本系列面向具备一定 Flutter/移动开发经验的工程师，深入讲解 googleads-mobile-flutter 插件的 `banner_example`，覆盖集成流程、同意管理、调试测试、上线合规与变现优化，帮助你快速落地可上线的 Banner 广告能力。

- 读者画像：熟悉 Flutter 基础，有广告或 SDK 集成经验的移动开发者。
- 学习目标：理解示例结构、完成 Banner 集成与调试、掌握同意管理与发布合规、具备指标优化思路。
