# 第 12 章 下一步与扩展

本章总结所学并给出扩展方向，帮助你在 Banner 之外继续提升广告能力。

## 简介

在掌握 Banner 基础后，你可以探索插页式、激励式和原生广告，并结合同意管理与调试工具构建完整的广告栈。

## 核心步骤

1. 参考插件文档尝试插页式或激励式广告，实现显示与回调处理。
2. 构建统一的广告服务层，封装不同广告格式的加载与错误处理。
3. 延伸指标监控：将曝光、点击事件上报到自有埋点体系，便于全链路分析。

## 代码示例

示例的同意管理与 SDK 初始化逻辑可复用到其他广告格式：

```dart
Future<void> initAdsIfAllowed() async {
  if (await _consentManager.canRequestAds()) {
    await MobileAds.instance.initialize();
    // 在此后加载其他广告类型
  }
}
```

## 练习与检查

- 新增一个插页式广告版位，沿用同意检查和错误日志模式。
- 尝试封装一个广告管理类，统一处理初始化、加载与销毁。
- 为广告事件添加自有埋点，验证数据能在分析后台可见。

## 小结

你已完成 Banner 基础与优化实践，可以继续扩展更多广告形式，并将同意、调试和监控纳入统一框架。
