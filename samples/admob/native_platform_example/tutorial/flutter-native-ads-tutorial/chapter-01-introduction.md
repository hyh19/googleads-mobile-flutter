# 第 1 章 原生广告简介

## 引言

原生广告（Native Ads）是一种与你的应用内容无缝融合的广告格式。与横幅广告或插屏广告不同，原生广告看起来就像应用内容的一部分，提供更好的用户体验和更高的参与度。本章将介绍原生广告的基本概念、特点、组成部分，以及为什么需要平台特定代码来实现它们。

## 什么是原生广告？

原生广告是一种广告格式，其外观和感觉与你的应用内容相匹配。它们被设计成看起来像应用的自然内容，而不是明显的广告。

### 核心特点

- **无缝融合**：广告看起来像应用内容的一部分
- **自定义布局**：你可以完全控制广告的外观和布局
- **高参与度**：用户更愿意与看起来像内容的广告互动
- **平台特定**：需要在 Android 和 iOS 平台使用原生代码实现

## 原生广告的优势

### 1. 更好的用户体验

原生广告不会像横幅广告那样打断用户浏览，也不会像插屏广告那样强制用户观看。它们自然地融入内容流中。

### 2. 更高的点击率

由于原生广告看起来像内容，用户更可能点击它们，从而获得更高的点击率（CTR）。

### 3. 更好的品牌体验

广告主可以创建与你的应用风格一致的广告，提供更好的品牌体验。

### 4. 更高的收益潜力

原生广告通常能获得更高的 eCPM（有效每千次展示成本），因为它们更受用户欢迎。

## 与其他广告格式的区别

### 原生广告 vs 横幅广告

- **横幅广告**：固定的矩形区域，明显是广告
- **原生广告**：自定义布局，看起来像内容

### 原生广告 vs 插屏广告

- **插屏广告**：全屏显示，打断用户体验
- **原生广告**：融入内容流，不打断用户体验

### 原生广告 vs 激励广告

- **激励广告**：用户主动选择观看以获得奖励
- **原生广告**：被动展示，但看起来像内容

## 原生广告的组成部分

原生广告由多个组件组成，有些是必需的，有些是可选的：

### 必需组件

- **Headline（标题）**：广告的主要标题
- **MediaView（媒体视图）**：显示图片或视频的视图

### 可选组件

- **Body（正文）**：广告的描述文本
- **Icon（图标）**：应用或产品的图标
- **Call to Action（行动号召）**：按钮文本，如"安装"、"了解更多"等
- **Price（价格）**：产品价格
- **Store（商店）**：应用商店名称
- **Star Rating（星级评分）**：应用的评分（1-5 星）
- **Advertiser（广告主）**：广告主的名称

## 为什么需要平台特定代码？

### 原生视图的必要性

原生广告需要在原生平台（Android/iOS）上使用原生视图来显示：

- **Android**：使用 `NativeAdView` 和 XML 布局
- **iOS**：使用 `NativeAdView` 和 XIB/Storyboard

### 工厂模式

Google Mobile Ads SDK 使用工厂模式来创建原生广告视图：

1. **Flutter 层**：请求加载原生广告，指定 `factoryId`
2. **原生层**：根据 `factoryId` 找到对应的工厂
3. **工厂创建视图**：工厂使用原生代码创建并配置广告视图
4. **返回视图**：视图被传递回 Flutter 层显示

### 工作流程

```text
Flutter 层
  ↓ 请求加载广告（factoryId: "adFactoryExample"）
原生层（Android/iOS）
  ↓ 查找对应的工厂
NativeAdFactory
  ↓ 创建 NativeAdView
  ↓ 填充广告数据
  ↓ 返回视图
Flutter 层
  ↓ 使用 AdWidget 显示
```

## 实现流程概览

集成原生广告的主要步骤：

1. **项目配置**：添加依赖和配置平台设置
2. **Android 实现**：
   - 创建 XML 布局文件
   - 实现 `NativeAdFactory` 接口
   - 在 `MainActivity` 中注册工厂
3. **iOS 实现**：
   - 创建 XIB 布局文件
   - 实现 `FLTNativeAdFactory` 协议
   - 在 `AppDelegate` 中注册工厂
4. **Flutter 集成**：
   - 加载原生广告
   - 使用 `factoryId` 匹配工厂
   - 使用 `AdWidget` 显示广告
5. **用户同意管理**：集成 UMP 以符合 GDPR 要求

## 原生广告的使用场景

### 1. 内容流中

在新闻、博客或社交媒体应用中，原生广告可以自然地插入到内容流中。

### 2. 应用列表

在应用商店或应用推荐列表中，原生广告可以看起来像其他应用条目。

### 3. 产品展示

在电商应用中，原生广告可以看起来像产品卡片。

### 4. 信息流

在任何信息流界面中，原生广告都可以无缝融入。
