# Flutter 原生广告（Native Ads）完整教程

本教程面向中级到高级 Flutter 开发者，帮助你深入学习如何在 Flutter 应用中集成 Google Mobile Ads 的原生广告（Native Ads）。如果你已经熟悉 Flutter 和原生开发（Android/iOS），想要了解如何使用平台特定代码实现原生广告，这个教程非常适合你。

## 学习目标

完成本教程后，你将能够：

- 理解原生广告的概念、特点和优势
- 在 Android 平台实现 `NativeAdFactory` 和布局设计
- 在 iOS 平台实现 `FLTNativeAdFactory` 和 XIB 布局
- 在 Flutter 层正确加载和显示原生广告
- 理解 `factoryId` 的作用和工厂注册机制
- 正确处理原生广告的必需字段和可选字段
- 集成用户同意管理（UMP）以符合 GDPR 要求
- 遵循最佳实践，优化原生广告体验
