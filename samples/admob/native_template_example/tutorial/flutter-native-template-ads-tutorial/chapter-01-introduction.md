# 第 1 章 原生模板广告简介

## 引言

原生模板广告（Native Template Ads）是 Google Mobile Ads 提供的一种简化的原生广告实现方式。与需要编写原生代码的平台特定实现不同，原生模板广告完全在 Flutter 层实现，使用 Google 提供的预定义模板，让你能够快速集成原生广告，无需原生开发经验。本章将介绍原生模板广告的基本概念、特点、优势，以及与平台特定实现的区别。

## 什么是原生模板广告？

原生模板广告是 Google 提供的预定义原生广告模板，允许开发者通过 Flutter 代码快速集成原生广告，而无需编写 Android 或 iOS 的原生代码。

### 核心特点

- **无需原生代码**：完全在 Flutter 层实现，不需要编写 Kotlin、Swift 或 XML/XIB 文件
- **预定义模板**：使用 Google 提供的模板布局，快速集成
- **样式自定义**：通过 `NativeTemplateStyle` 配置颜色、字体等样式
- **简单易用**：适合快速集成，降低开发门槛

## 原生模板广告的优势

### 1. 快速集成

原生模板广告最大的优势是快速集成。你只需要：

1. 添加依赖
2. 配置样式
3. 加载和显示广告

无需编写原生代码，无需注册工厂，无需设计布局文件。

### 2. 降低开发门槛

- **不需要原生开发经验**：完全在 Flutter 层实现
- **不需要设计布局**：使用预定义模板
- **减少维护成本**：不需要维护原生代码

### 3. 一致的跨平台体验

原生模板广告在 Android 和 iOS 上提供一致的体验，无需为不同平台编写不同的代码。

### 4. 灵活的样式配置

虽然使用预定义模板，但你仍然可以通过 `NativeTemplateStyle` 自定义：

- 背景颜色
- 文本颜色和字体样式
- 字体大小
- 行动号召按钮样式

## 与平台特定实现的区别

### 原生模板广告 vs 平台特定实现

| 特性 | 原生模板广告 | 平台特定实现 |
|------|------------|-------------|
| **原生代码** | 不需要 | 需要（Kotlin/Swift） |
| **布局设计** | 预定义模板 | 自定义 XML/XIB |
| **工厂注册** | 不需要 | 需要注册 `NativeAdFactory` |
| **自定义程度** | 中等（样式配置） | 高（完全自定义） |
| **开发时间** | 短 | 长 |
| **维护成本** | 低 | 高 |
| **适用场景** | 快速集成、标准布局 | 高度定制、品牌化需求 |

### 何时使用原生模板广告？

适合使用原生模板广告的场景：

- **快速集成**：需要快速集成原生广告
- **标准布局**：预定义模板满足需求
- **无原生开发经验**：团队没有原生开发能力
- **跨平台一致性**：需要 Android 和 iOS 一致的体验

### 何时使用平台特定实现？

适合使用平台特定实现的场景：

- **高度定制**：需要完全自定义的广告布局
- **品牌化需求**：广告需要与应用设计完全融合
- **特殊布局**：预定义模板无法满足需求
- **有原生开发能力**：团队有 Android 和 iOS 开发经验

## 模板类型概览

原生模板广告提供两种模板类型：

### Small 模板

- **尺寸比例**：91/355（宽高比）
- **特点**：紧凑型布局，适合较小的展示空间
- **使用场景**：列表项、侧边栏、小卡片

### Medium 模板

- **尺寸比例**：370/355（宽高比）
- **特点**：标准型布局，适合主要展示区域
- **使用场景**：内容流、主页面、大卡片

## 实现流程概览

集成原生模板广告的主要步骤：

1. **项目配置**：添加依赖和配置平台设置
2. **选择模板类型**：根据需求选择 small 或 medium
3. **配置样式**：使用 `NativeTemplateStyle` 自定义样式
4. **加载广告**：创建 `NativeAd` 并设置 `nativeTemplateStyle`
5. **显示广告**：使用 `AdWidget` 显示广告
6. **处理事件**：通过 `NativeAdListener` 处理广告事件
7. **用户同意管理**：集成 UMP 以符合 GDPR 要求

## 工作流程

```text
Flutter 层
  ↓ 创建 NativeAd（设置 nativeTemplateStyle）
  ↓ 加载广告
Google Mobile Ads SDK
  ↓ 使用预定义模板渲染
  ↓ 返回渲染后的视图
Flutter 层
  ↓ 使用 AdWidget 显示
```

## 原生模板广告的组成部分

虽然使用预定义模板，但模板包含以下标准组件：

- **Headline（标题）**：广告的主要标题
- **Body（正文）**：广告的描述文本
- **Icon（图标）**：应用或产品的图标
- **MediaView（媒体视图）**：显示图片或视频
- **Call to Action（行动号召）**：按钮文本，如"安装"、"了解更多"等
- **Advertiser（广告主）**：广告主的名称
- **Star Rating（星级评分）**：应用的评分（如果适用）

这些组件由 Google 的模板自动布局，你只需要配置样式。
