# Flutter 原生模板广告（Native Template Ads）完整教程

本教程面向中级 Flutter 开发者，帮助你快速学习如何在 Flutter 应用中集成 Google Mobile Ads 的原生模板广告（Native Template Ads）。如果你想要快速集成原生广告，不需要原生开发经验，这个教程非常适合你。

## 学习目标

完成本教程后，你将能够：

- 理解原生模板广告的概念、特点和优势
- 了解原生模板广告与平台特定实现的区别
- 选择合适的模板类型（small 或 medium）
- 通过 `NativeTemplateStyle` 自定义广告样式
- 在 Flutter 中加载和显示原生模板广告
- 处理原生模板广告的各种事件
- 集成用户同意管理（UMP）以符合 GDPR 要求
- 遵循最佳实践，优化原生模板广告体验
