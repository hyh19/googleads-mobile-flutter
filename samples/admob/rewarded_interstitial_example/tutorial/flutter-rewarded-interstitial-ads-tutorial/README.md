# Flutter Rewarded Interstitial Ads 完整教程

本教程面向中级 Flutter 开发者，帮助你从零开始学习如何在 Flutter 应用中集成 Google Mobile Ads 的激励插屏广告（Rewarded Interstitial Ads）。如果你已经熟悉 Flutter 开发，但对 Google Mobile Ads 还不了解，这个教程非常适合你。

## 学习目标

完成本教程后，你将能够：

- 理解 Rewarded Interstitial Ads 的特点和使用场景
- 掌握与 Rewarded Ads 的区别，能够选择合适的广告格式
- 在 Flutter 项目中正确配置 Google Mobile Ads SDK
- 实现广告的加载、显示和事件处理
- 实现符合 Google 政策要求的介绍屏幕（Intro Screen）
- 集成用户同意管理（UMP）以符合 GDPR 要求
- 实现完整的奖励机制和游戏逻辑
- 遵循最佳实践，优化用户体验
