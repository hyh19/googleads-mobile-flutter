# 第 1 章：Interstitial Ads 简介

## 章节简介

在本章中，我们将介绍 Interstitial Ads（插屏广告）的基本概念、使用场景和优势，帮助你理解为什么以及何时应该使用这种广告格式。我们还将概述实现 Interstitial Ads 的完整流程，为后续章节的学习打下基础。

## 什么是 Interstitial Ads

Interstitial Ads（插屏广告）是一种全屏广告格式，占据整个屏幕，通常在应用的自然过渡点显示。与 Banner Ads 不同，Interstitial Ads 会完全覆盖应用内容，用户必须关闭广告才能继续使用应用。

### 核心特征

Interstitial Ads 具有以下核心特征：

- **全屏展示**：占据整个屏幕，提供沉浸式体验
- **过渡点显示**：在应用的自然过渡点显示，如关卡结束、任务完成等
- **高参与度**：用户必须与广告交互才能关闭，提高广告参与度
- **高收益潜力**：全屏展示和强制交互带来更高的广告收益

## 使用场景和优势

### 典型使用场景

Interstitial Ads 最适合以下场景：

1. **游戏关卡结束**：玩家完成关卡后显示广告
2. **任务完成**：用户完成任务或达到里程碑时显示
3. **内容切换**：从一个内容切换到另一个内容时显示
4. **应用恢复**：从后台恢复应用时显示（但要注意用户体验）

### 主要优势

使用 Interstitial Ads 可以带来以下优势：

- **高收益**：全屏展示和强制交互带来更高的广告收益
- **高参与度**：用户必须与广告交互，提高点击率
- **自然集成**：在应用的自然过渡点显示，不会显得突兀
- **灵活控制**：可以精确控制广告的显示时机

## 与其他广告格式的区别

为了更好地理解 Interstitial Ads，让我们将其与其他常见的广告格式进行对比：

### Interstitial Ads vs Banner Ads

| 特性 | Interstitial Ads | Banner Ads |
|------|----------------|-----------|
| 显示方式 | 全屏显示 | 部分屏幕显示 |
| 用户交互 | 必须关闭才能继续 | 可以忽略继续使用 |
| 显示时机 | 应用过渡点 | 持续显示 |
| 视觉冲击 | 高 | 中等 |
| 收入潜力 | 高 | 中等 |

### Interstitial Ads vs App Open Ads

| 特性 | Interstitial Ads | App Open Ads |
|------|----------------|-------------|
| 触发时机 | 在应用内的特定时刻手动触发 | 应用切换到前台时自动显示 |
| 使用场景 | 关卡结束、任务完成等 | 应用启动、恢复 |
| 生命周期 | 与应用生命周期独立 | 与应用生命周期绑定 |
| 预加载 | 可以按需加载 | 必须在显示前预加载 |

## 实现流程概览

实现 Interstitial Ads 的完整流程包括以下主要步骤：

### 1. 项目配置

- 添加 `google_mobile_ads` 依赖
- 配置 Android 和 iOS 平台
- 获取广告单元 ID

### 2. 加载广告

- 使用 `InterstitialAd.load()` 方法请求广告
- 实现 `InterstitialAdLoadCallback` 处理加载结果
- 保存加载的广告对象

### 3. 设置事件回调

- 实现 `FullScreenContentCallback` 处理广告事件
- 处理广告展示、关闭、点击等事件

### 4. 显示广告

- 在合适的时机调用 `show()` 方法
- 确保广告已加载完成

### 5. 资源管理

- 在广告关闭后释放资源
- 在 Widget 销毁时清理资源

### 6. 集成同意管理

- 实现用户同意管理（UMP）
- 在获得同意后加载广告

## 核心概念

在深入学习实现细节之前，让我们先了解几个核心概念：

### 广告单元 ID（Ad Unit ID）

广告单元 ID 是 Google AdMob 为你的应用分配的唯一标识符，用于标识特定的广告位置。每个平台（Android 和 iOS）都有独立的广告单元 ID。

### 广告加载（Ad Loading）

广告加载是指从 Google 广告服务器请求广告内容的过程。Interstitial Ads 需要在显示之前完成加载，这通常需要几秒钟的时间。

### 广告显示（Ad Showing）

广告显示是指将已加载的广告呈现给用户的过程。只有在广告成功加载后，才能进行展示。

### 广告事件（Ad Events）

广告事件是在广告生命周期的不同阶段触发的回调，用于处理广告加载、展示、关闭等事件。

### 显示时机（Timing）

显示时机是指何时显示广告。选择合适的时机对于用户体验和广告效果都非常重要。
